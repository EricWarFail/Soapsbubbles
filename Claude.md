Create a mobile-first web application that displays a motivational quote.

Requirements:

* The page should show one motivational quote centered on the screen.
* Each time the page reloads, a new random quote should appear.
* Include a button labeled "New Quote" that fetches another random quote without reloading.
* Design should be minimal, clean, and optimized for mobile (responsive, large readable text, centered layout).
* Use smooth transitions when changing quotes (fade or slide).
* Include a small footer or subtle branding area.

Data:

* Start with a local array of at least 20 motivational quotes.
* Then optionally integrate an API call to OpenAI (ChatGPT) to generate new motivational quotes dynamically.
* If API is used, include a fallback to local quotes if the API fails.

Technical:

* Use plain HTML, CSS, and JavaScript (no frameworks).
* Keep everything in a single file if possible.
* Use modern ES6+ JavaScript.
* Make sure the UI is fast and works well on mobile browsers.

Optional Enhancements:

* Add a "Copy Quote" button.
* Add dark/light mode toggle.
* Add subtle animations.

Output:

* Provide complete working code.
* Clearly separate HTML, CSS, and JS sections.
* Comment important parts of the code.
